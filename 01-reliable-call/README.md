# 01｜可靠调用起步

## 当前问题

调用方如何接收成功响应，并区分提供者返回与提供者抛出异常？

## 已有实现

- `fake_provider(messages, mode="ok")`：从最后一条消息读取内容，返回包含 `text` 的字典。
- `mode="timeout"`：主动抛出 `TimeoutError`，由调用方捕获。
- 未知模式：抛出 `ValueError`，由调用方捕获。
- 调用方包含未收到响应时的提示；它目前只检查 `None`，不等于完整响应校验。

## 运行

在仓库根目录执行：

```powershell
python -X utf8 .\01-reliable-call\main.py
```

当前脚本依次演示成功、模拟超时、未知模式三条路径。

## 实现边界与下一步

这里没有真实模型调用，也没有等待计时、网络连接、实际超时或自动重试。响应校验函数目前尚未实现，下一步由学习者完成字典、字段存在、字符串类型和非空白内容的校验，并通过合法/坏响应和既有路径检查。

本次仓库初始化保存当前代码基线，不表示整个可靠调用单元已完成。
